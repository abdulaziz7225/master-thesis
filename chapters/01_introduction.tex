\chapter{Introduction}
\label{chap:introduction}

\section{Context}
The modern cloud landscape is dominated by microservices and containerization. However, as the demand for edge computing and high-density serverless functions grows, the overhead of traditional containers becomes a limiting factor. This section introduces the shift toward lightweight execution environments.

\section{Problem Statement}
Standard OCI containers (like Docker) introduce significant overhead in terms of memory footprint and cold-start latency. This thesis addresses the inefficiency of using full OS-level virtualization for small, transient microservices.

\section{Research Questions}
\begin{itemize}
    \item \textbf{RQ1:} How does the memory footprint of WebAssembly modules compare to traditional Docker containers in a Kubernetes environment?
    \item \textbf{RQ2:} Can WebAssembly runtimes offer superior startup performance compared to standard container runtimes?
\end{itemize}
